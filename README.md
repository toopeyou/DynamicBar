Sales Analytics Dashboard
A responsive sales analytics dashboard built with Next.js, React, TypeScript, and Tailwind CSS. It provides an overview of sales performance through interactive statistics, charts, and filtering tools.

Features
Sales Overview — visualize monthly sales performance using charts.
Key Metrics — track total sales, total orders, and average sale value.
Interactive Filters — filter sales data by date range, category, and region.
CSV Export — export filtered sales records to a CSV file.
Data Table — view monthly sales data in a structured table.
Dark Mode — switch between light and dark themes.
Responsive Design — optimized for desktop and mobile devices.
Tech Stack
Next.js 16 — React framework.
React 19 — UI library.
TypeScript — static typing.
Tailwind CSS 4 — styling.
Lucide React — icons.
Getting Started
Prerequisites
Make sure you have installed:

Node.js
npm
Installation
Clone the repository:

bash
git clone https://github.com/toopeyou/test.git
Navigate to the project directory:

bash
cd test
Install dependencies:

bash
npm install
Start the development server:

bash
npm run dev
Open http://localhost:3000 in your browser.

Usage
Open the dashboard.
Select a date range to analyze a specific period.
Filter sales data by category or region.
Review key performance metrics and monthly sales charts.
Export the filtered records using the Export CSV button.
Switch between light and dark themes as needed.
